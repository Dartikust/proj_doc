# DocFlow — реестр договоров

Каркас корпоративного веб-сервиса на FastAPI для загрузки PDF/DOCX, хранения договоров и работы с их реквизитами.

## Уже работает

- загрузка PDF и DOCX;
- сохранение файлов в `uploads/`;
- SQLite-база `contracts.db` создаётся автоматически;
- профессиональный адаптивный интерфейс в спокойном корпоративном стиле;
- реестр документов;
- единый поиск по номеру, имени файла, заказчику, исполнителю и сумме;
- фильтры по диапазону дат, сумме и статусу;
- сортировка по дате, сумме, номеру, имени файла и времени загрузки;
- сортировка кликом по заголовкам таблицы;
- пагинация по 25 документов;
- страница отдельного договора;
- ручное редактирование 4 требуемых реквизитов: номер, дата, стороны, сумма;
- скачивание и удаление загруженного файла;
- нормализованные служебные поля `contract_date_iso` и `amount_value`, чтобы дата и сумма сортировались как дата и число, а не как строки.

## Пока заглушка

`parser.py` пока не извлекает текст и реквизиты. На следующем этапе туда можно подключить `python-docx`, `PyMuPDF`/`pypdf`, RegEx, Natasha или модель. Интерфейс, база, фильтры и сортировка уже готовы.

## Запуск

Windows PowerShell:

```powershell
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
uvicorn main:app --reload
```

`http://127.0.0.1:8000`
